# Hola 👋, soy Daniel Medina

### Frontend Developer | React · Next.js · TypeScript

📍 Buenos Aires, Argentina

Soy desarrollador Frontend especializado en React, Next.js y TypeScript, enfocado en la creación de interfaces modernas, accesibles y centradas en la experiencia del usuario.

Participé en el desarrollo de ViaCore, una plataforma SaaS para la gestión de capacitaciones corporativas, donde trabajé en funcionalidades relacionadas con autenticación, gestión de usuarios, reuniones, pagos, notificaciones e integración de APIs. Esta experiencia me permitió fortalecer mis conocimientos técnicos y colaborar en un entorno de desarrollo con metodologías ágiles.

Actualmente continúo ampliando mis habilidades mediante proyectos personales y colaborativos, con interés en construir aplicaciones escalables, optimizar la experiencia de usuario y seguir creciendo profesionalmente dentro del ecosistema Frontend.
